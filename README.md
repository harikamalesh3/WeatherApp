# Weather App 🌦️

A weather application built using modern web technologies.


## 📁 Project Structure

- **backend/** – Backend server and API.
- **frontend/** – Frontend application.
- **screenshots/** – Project screenshots.

## 🛠️ Technologies Used

- React.js
- Node.js
- Express.js
- JavaScript
- CSS

## 🚀 Installation

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
